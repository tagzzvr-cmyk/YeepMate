# YeepMate ♟️

A fan-made, two-player chess experience themed around Yeeps.

## Play locally

Open `index.html` in a browser. An internet connection is needed to load the chess rules library from CDNJS.

## Features

- Classic chess rules and legal move validation
- Two players taking turns on one device
- Check, checkmate, stalemate and draw detection
- Move history, undo and new game controls
- Responsive black-and-white chessboard with custom block-inspired pieces

## GitHub Pages

In the repository, open **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/(root)**, then save.

The site will be available at `https://tagzzvr-cmyk.github.io/YeepMate/` after GitHub Pages finishes deploying.
